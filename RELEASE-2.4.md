# Custom Rodin characters — 2.4.0

The finished local game has two custom textured and animated robots: a mint rescue guardian and a coral armored stalker. They replace the squad and humanoid pursuers. Local Blender created their skeletons and running loops; each character has 2,700 triangles. Existing drones and spitters complete the swarm.

Open **Play Neon Swarm.cmd** in the Desktop game folder to play. Open **character-gallery.html** to rotate the characters, pause animation, view a 150-pursuer crowd drill, or download animated GLBs. Editable Blender scenes are under `assets/characters/rodin/`.

All 48 automated checks pass. Desktop and phone-layout checks cover the new models, gallery framing, pointer steering, pause and saving. The Desktop files match the verified source archive. Direct-file browser testing is unavailable in Codex's in-app browser because its URL policy blocks file://; all runtime dependencies are saved locally or embedded.

Rodin used **1.5 of the 7 existing credits**, leaving **5.5**. No subscription or credit purchase was made. Original models, references, prompts, hashes and costs are retained. See ASSETS.md and RODIN-ASSET-PLAN.md.
